# Radio Garden PL

Prosta aplikacja webowa z mapą stacji radiowych, globusem, wyszukiwaniem, ulubionymi i odtwarzaczem audio.

## Uruchomienie

W katalogu projektu uruchom:

```bash
npm start
```

Następnie otwórz w przeglądarce:

```text
http://localhost:4173
```

## Funkcje

- mapa Leaflet z lokalizacjami stacji
- tryb globusa
- wyszukiwanie po nazwie, kraju i gatunku
- ulubione i ostatnio słuchane
- tryb ciemny/jasny
- tryb kosmiczny z orbitami i satelitami
- odtwarzanie strumieni audio z radio-browser.info

## Uwagi

Aplikacja jest statyczna i nie wymaga instalacji zależności. Serwer jest dostarczony w pliku `server.js` i działa na Node.js.
